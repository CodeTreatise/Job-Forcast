# TechTalentIQ — IT Job Market Intelligence & Career Modernizer Terminal

A full-stack, data-driven IT labor market intelligence and legacy technology career transition platform. Designed to provide deep structural insights into engineering compensation, technology adoption shifts, hiring velocity, and concrete step-by-step upskilling roadmaps for modernizing legacy tech stacks.

![TechTalentIQ Preview](https://raw.githubusercontent.com/shivpalmurgude/techtalentiq/main/preview.png)

---

## 🚀 Key Modules & Capabilities

- **Legacy Tech Modernizer & Career Pivot Engine:** Detailed blueprints for legacy titles and stacks (AngularJS/Angular 2-16, Manual QA, Java Monoliths, Sysadmin, PHP, ETL, DBA) transitioning to Cloud-Native, Modern React, AI Ops, and SRE. Includes skill delta matrices, capstone project architectures, and step-by-step action plans.
- **Global Labor Market Terminal:** Comprehensive compensation intelligence across 9 global currencies with dynamic Purchasing Power Parity (PPP) adjustments.
- **Deep Tech Longevity & Frontier Matrix:** Analyzes capital inflows, longevity scores, and displacement probabilities across AI/ML Infra, Distributed Systems, Cloud Architecture, and DevOps.
- **Real-Time Deep Research Synthesis:** Search-grounded Gemini intelligence generating structured labor reports with verifiable data citations and sources.
- **Job Application Tracker:** Built-in tracker with interactive filters, application status workflows, and persistence in local storage.

## 📦 Getting Started

### Prerequisites

- Node.js 20+ (Node 22 recommended)
- npm or bun

### Installation

```bash
# Clone the repository
git clone <your-repo-url>
cd <repo-folder>

# Install dependencies
npm install
```

### Development Mode

```bash
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Production Build

```bash
npm run build
```

The optimized static assets will be output to the `dist/` directory.

---

## 🌐 Deploy to GitHub Pages (1-Click)

The repository includes a ready-to-run GitHub Actions workflow (`.github/workflows/deploy.yml`):

1. Push this repository to GitHub.
2. Go to your repository **Settings** → **Pages**.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. The deployment will run automatically on push to `main` and your site will be live at `https://<username>.github.io/<repo-name>/`.
